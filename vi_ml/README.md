# vi_ml — 価値反復の CNN サロゲート

`vi_lib` の u64 ソルバ（`bench_map`）を教師にして、占有格子＋ゴールから
θ 最小の価値場（秒）を U-Net で回帰し、貪欲降下で経路が出るかを測る。

```
cd vi_ml && uv sync                 # 初回のみ（torch CPU 版）
make ml-data                        # bench_map を build → 64² を 4000 枚、128² を 600 枚解いて out/*.npz
make ml-train                       # U-Net 学習 → out/unet.pt
make ml-eval                        # 値誤差・到達率・経路長比・時間、続けてピラミッド走行
make ml-test
```

| ファイル | 役割 |
|---|---|
| `vi_ml/maps.py` | 地図生成: 部屋＋廊下(BSP) / 迷路 / ブロブ / tb3_house の切り出し。壁は `thicken` で 1 セル膨張（VI は遷移先セルしか見ないので 1 セル壁は 3 セル前進に抜けられる） |
| `vi_ml/vi.py` | PGM+YAML を書いて `bench_map --dump-value` を呼ぶ。セル 0.1 m、safety 0.2 m / 30 s、`frontier2d_sparse` |
| `vi_ml/dataset.py` | 上 2 つを回して `.npz`（free, goal, value, solve_ms, kind） |
| `vi_ml/model.py` | 4ch 入力（free, goal, 境界値, 境界マスク）→ log 正規化した値場の U-Net。境界 ch は窓モード用 |
| `vi_ml/rollout.py` | 半径 3 セル・見通し付きの貪欲降下（真の値場で 100/100 到達） |
| `vi_ml/train.py` | 64² 全体 ＋ 128² から切った 64² 窓（境界 2 セルに真値）を混ぜて学習 |
| `vi_ml/eval.py` | 保留 400 枚で U-Net vs 厳密解 |
| `vi_ml/pyramid.py` | 128² を 2× プールした粗場を CNN で出し、ロボット周辺の 64² 窓の境界に流し込んで細場を CNN で出し、8 歩進んで窓を動かす |

## 結果（2026-09-03、U-Net 4.4M、25 エポック、val L1 0.013、CPU 1 スレッド）

保留 400 枚の 64²（`make ml-eval` 前半）:

| kind | n | rel.err | success(pred) | success(true) | len ratio | cnn ms | vi ms |
|---|---|---|---|---|---|---|---|
| blobs | 94 | 0.605 | 0.577 | 1.000 | 1.01 | 25.5 | 43.8 |
| crop | 78 | 0.071 | 0.835 | 1.000 | 1.02 | 24.9 | 36.5 |
| maze | 72 | 0.201 | 0.253 | 1.000 | 1.05 | 25.8 | 139.2 |
| rooms | 156 | 0.229 | 0.346 | 0.990 | 1.02 | 25.9 | 76.5 |
| all | 400 | 0.281 | 0.479 | 0.996 | 1.02 | 25.6 | 59.6 |

保留 100 枚の 128² × 4 始点のピラミッド走行（後半）:

| kind | runs | success(pyramid) | success(true greedy) | len ratio | pyramid ms | vi ms |
|---|---|---|---|---|---|---|
| blobs | 100 | 0.480 | 1.000 | 1.04 | 106 | 97 |
| crop | 100 | 0.450 | 1.000 | 1.04 | 135 | 116 |
| maze | 76 | 0.013 | 1.000 | 1.11 | 135 | 1061 |
| rooms | 124 | 0.411 | 1.000 | 1.06 | 143 | 224 |
| all | 400 | 0.362 | 1.000 | 1.05 | 132 | 173 |

読み方: 値の相対誤差は小さい（crop 7 %）のに貪欲降下の到達率が 48 % で、失敗は全て局所最小（歩数上限に当たった例はゼロ、詰まった点の真値の中央値は 135 s でゴールから遠い）。
つまり場の大まかな形は合っていて、小さな凹凸が降下を止めている。時間は 64² で CNN 26 ms 対 VI 60 ms、ピラミッドは 132 ms 対 173 ms で、この大きさでは速度の勝ちもない。迷路は 1 % で、受容野の限界がそのまま出ている。

次の候補: 拡散生成モデル（値場の条件付き生成）との比較、CNN の粗場を warm start にして `vi_lib` の `resweep` で厳密解まで持っていく版。
